快速上手

            
    
              
  1. 在“需求工作台”输入你想让 AI 做的事，可以是问题、开发需求、图片描述、文案任务或分析任务。
    2. 
              
  2. 点击“生成精准提示词”。右侧会生成完整提示词、版本对比、结构拆解和评分。
    3. 
              
  3. 如果你不知道怎么写，可以先从左侧“模板中心”选择模板，再把模板内容改成自己的需求。
    4. 
              
  4. 生成后优先查看“完整提示词”。如果太长或太短，再切到“版本对比”选择合适版本。
    5. 
            

          


          

            
输入区怎么用

            
输入越具体，生成的提示词越精准。建议至少写清楚：目标、对象、场景、期望输出、限制条件。

            

              不够清楚：
              
帮我做一个网站。

              更好：
              
帮我创建一个咖啡店会员管理网站，需要会员档案、消费记录、优惠券、数据看板，界面要高级，适合电脑和手机使用。

            

            
“生成提示词”适合从零开始整理需求；“改写提示词”适合你已经有一段提示词，但觉得它太粗糙、太短或不够专业。

          


          

            
追问模式

            
当需求比较模糊时，先回答追问问题。系统会把你的回答合并到原需求里，再生成更完整的提示词。

            
    
              
  • 不是每一题都必须填，只填你知道的部分即可。
    • 
              
  • 开发类任务重点补充页面、技术栈、数据和运行方式。
    • 
              
  • 图片类任务重点补充主体、风格、构图、光线和画幅。
    • 
              
  • 分析类任务重点补充时间范围、指标、数据来源和决策目标。
    • 
            

          


          

            
模板中心

            
模板适合不知道如何开始的用户。点击模板后，系统会自动填入示例需求，并切换到对应场景。

            
    
              
  • 搜索框可以搜“网站”“图片”“文案”“分析”“简历”等关键词。
    • 
              
  • 分类按钮可以快速筛选开发、图片、写作、商业和个人场景。
    • 
              
  • 模板只是起点，最好根据自己的业务或目标继续修改。
    • 
            

          


          

            
结果区怎么看

            
    
              
  • 完整提示词：最推荐复制给 AI 使用的主版本。
    • 
              
  • 版本对比：提供简洁版、专业版、超详细版、可直接复制版，适合不同复杂度。
    • 
              
  • 结构拆解：告诉你这条提示词由哪些部分组成，方便继续修改。
    • 
              
  • 图片参数：当场景是图片生成时，会给出正向提示词、负面提示词和画幅建议。
    • 
              
  • 评分：用于判断需求是否足够清楚，分数低时建议补充上下文和约束。
    • 
            

          


          

            
保存、收藏、导出和分享

            
    
              
  • 保存历史：把当前结果保存到浏览器本地历史。
    • 
              
  • 收藏：把常用提示词放进收藏列表，方便以后再次打开。
    • 
              
  • 导出 TXT / MD：把提示词保存成文本或 Markdown 文件。
    • 
              
  • 分享链接：生成一个包含当前输入和设置的链接，别人打开后可以继续编辑。
    • 
            

            
历史和收藏默认保存在当前浏览器里，换电脑或清理浏览器数据后可能会丢失。

          


          

            
AI 增强与云端同步

            
基础功能不需要后端地址，打开网页就能用。AI 增强和云端同步属于高级功能，需要你自己配置后端接口。

            
    
              
  • AI 增强：填写后端地址后，系统会把需求和设置发送给后端，让真正的 AI 进一步优化结果。
    • 
              
  • 云端同步：填写同步端点后，可以把历史和收藏发送到你的服务端。
    • 
              
  • 重要：不要把 OpenAI、DeepSeek 或其他模型 API Key 直接写在网页前端代码里。
    • 
            

          


          

            
常见问题

            

              为什么没有填 AI 后端也能生成？
              
因为网站内置了本地规则引擎，可以离线生成结构化提示词。AI 后端只是增强效果，不是基础使用的必要条件。

            

            

              提示词太长怎么办？
              
切到“版本对比”，选择简洁版；也可以把“细节密度”调低。

            

            

              我应该选哪个场景？
              
不确定时保持“自动”。如果识别不准，再手动选择问答、开发、图片、写作或分析。

            

            

              如何得到更好的图片提示词？
              
写清楚主体、背景、镜头、光线、材质、颜色、风格和画幅。不要只写“生成一张好看的图片”。
