# PromptLens

一个用于把原始需求转换成高质量 AI 提示词的静态网站。

## 功能

- 自动识别问答、开发、图片、写作、分析等场景
- 生成结构化精准提示词
- 输出结构拆解和图片生成参数
- 支持复制、历史保存、暗色模式和移动端布局

## GitHub Pages 发布

将本目录内文件上传到公开 GitHub 仓库后，在仓库设置中开启 Pages：

- Source: Deploy from a branch
- Branch: main
- Folder: /root

发布后网站地址通常是：

```text
https://<github-user>.github.io/<repo-name>/
```
